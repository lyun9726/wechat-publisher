# 研究与选题

## 选题筛选

用户问“今天写什么”时，先查看近 12 到 24 小时与账号定位相关的新信息。目标环境有 AIHOT Skill 时可以用它发现候选，但仍要打开原始来源核验。没有 AIHOT 就查官方博客、项目仓库、产品更新页、论文和可靠行业媒体。

给出三个候选时，每个候选都要说明：

- 刚发生了什么，以及发生时间。
- 读者为什么会点开，文章能交付什么实际收益。
- 一手材料是否足够，能否配到真实图片。
- 与近期已写文章是否重复。

优先选择同时具备新信息、明确读者问题、可演示动作和真实素材的题目。单纯参数更新、来源模糊的传闻和只能复述新闻的题目降级。

## 事实核验

- 产品发布、模型能力、价格、下载量、排行榜和政策属于动态信息，写作当日重新确认。
- 关键结论尽量由官方公告、官方文档、论文、项目仓库或真实运行结果支撑。
- GitHub 项目至少检查 README、许可证、最近提交、安装要求和示例产物。README 中的宣传语仍属于项目方自述。
- 榜单写清榜单名、模式、时间和范围。“国产第一”必须说明在哪张榜单、哪种任务、截至何时。
- 成本下降要写清口径。评测任务成本、API 单价和用户实际账单不能混为一谈。
- 外部文章可以提供线索和角度，不能照搬结构、段落、标题组合或未核验结论。

## 来源文件

`sources.md` 对每个关键来源至少记录：

- 页面标题与直接链接。
- 发布或更新日期，若页面提供。
- 核验日期。
- 它支持正文中的哪条结论。
- 属于官方事实、项目方自述、第三方评测还是作者判断。

引用图片时同时记录图片来源页。公开材料写成的文章在文末保留少量真正重要的链接，不把整份检索笔记塞进正文。
