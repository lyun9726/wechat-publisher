# 兼容与降级

这套 Skill 可以被支持 Agent Skills 的环境读取，但自动化深度取决于目标 Agent 的工具。

## 最小能力

只有文件和网络工具时，仍可完成研究、写作、来源、图片计划和文章包。已有本地图片时也能运行 `build_copyable.py` 生成独立 HTML。

## 推荐能力

- 浏览器读取与操作，用于官方截图、HTML 预览和公众号后台。
- 本地文件读写与命令执行，用于初始化、图片处理和校验脚本。
- 图片生成或图像编辑，用于用户明确需要的封面和插画。
- 剪贴板 HTML 读取能力，用于验证公众号富文本。

## 降级原则

- 没有图片工具，不生成假图，交付 `image-plan.md` 和截图位置。
- 没有浏览器控制，仍可生成并静态审计 `带图可复制版.html`，但说明尚未完成浏览器预览和实际粘贴验收。
- 无法读取 HTML 剪贴板，不得声称公众号后台和手机端已经通过，只能说明独立 HTML 已内嵌图片并通过静态审计。
- 无法访问公众号后台，停在经过审计的富文本或本地文章包。
- 没有图片工具时，不生成假截图，交付 `image-plan.md`、来源链接和具体截图区域。

不同 Agent 的浏览器工具名称不同。Skill 只规定可观察结果，不要求某一种工具。执行时优先使用目标环境原生的浏览器、截图、图片和文件能力。工具不全时保留可以交给下一个 Agent 继续的文件，不用文字假装已经做完。
