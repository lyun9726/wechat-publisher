# 工作流与完成条件

## 四种交付深度

### 文章稿

适用于“写一篇”“改一下”“仿写但不要照抄”。交付 `brief.md`、`sources.md` 和 `article.md`。事实材料不足时先研究；私人体验缺失时最多一次问三个问题，用户要求直接写则缩小题目或缩短篇幅。

### 图文包

在文章稿基础上增加 `image-plan.md`、`images/` 和图片引用。产品与教程稿先找官方截图。封面是第一张图，推荐 900×383。用户明确只要一张首图时，不自动增加正文图。

### 带图复制版

在图文包基础上生成 `article-raphael.md`，导入 Raphael，检查手机视图，再验证剪贴板 HTML。网页预览正确但剪贴板仍是旧稿或本地图片地址，均算失败。

### 公众号草稿或发布

登录、粘贴、填写标题摘要、设置封面和保存草稿都属于外部账户操作。用户明确要求保存草稿时可以执行。正式发布必须获得针对当前文章和当前账号的明确确认。

## 推荐顺序

1. 读取项目内 `author-profile.json`，没有就保持中性。
2. 建立文章目录和写作卡。
3. 对公开材料做时效核验，记录关键来源。
4. 写初稿并复核事实、标题承诺和语言。
5. 按用户要求制作图片，完成图片计划。
6. 运行包校验，生成 Raphael 版本。
7. 用真实输入或粘贴事件导入 Raphael。
8. 检查手机预览和每张图片的自然尺寸。
9. 复制到公众号并审计剪贴板 HTML。
10. 根据授权停在复制、草稿或发布阶段。

## 文章包约定

```text
runs/<slug>/
├── author-profile.json
├── brief.md
├── sources.md
├── article.md
├── article-raphael.md
├── image-plan.md
├── delivery-check.md
└── images/
    ├── 00-cover.png
    └── 01-example.png
```

## 不得提前宣布完成

- 研究稿缺少关键来源。
- 图片计划中的完成图片没有写入正文。
- Raphael 预览存在裂图或过小文字。
- 编辑器内容与剪贴板内容不是同一稿。
- 剪贴板 HTML 缺当前指纹，或含上一篇指纹。
- HTML 仍含本机地址。
- 用户要草稿，但草稿没有实际保存。
