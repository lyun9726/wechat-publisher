## 交付要求

- 正文 Markdown 中每张图都有可读取的文件。
- Raphael 手机视图没有裂图、拉伸或小到无法阅读的文字。
- 剪贴板 HTML 图片数量不少于状态为完成的图片数量。
- HTML 不含本地服务器地址、本机路径或失效链接。
