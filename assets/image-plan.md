## 交付要求

- 正文 Markdown 中每张图都有可读取的文件。
- 封面是正文最后一张图，设置公众号封面后可以删除。
- 带图 HTML 的桌面与窄屏预览没有裂图、拉伸或小到无法阅读的文字。
- HTML 图片数量等于状态为完成且写入正文的图片数量。
- HTML 不含本地服务器地址、本机路径或失效链接。
